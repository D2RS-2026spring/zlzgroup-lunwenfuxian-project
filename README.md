## 二、项目内容

本项目研究基于功能视角的经济林恢复对土壤物理质量的影响。围绕不同植被恢复方式下土壤物理性质、土壤功能及综合土壤物理质量指数之间的关系展开，重点分析经济林恢复过程中土壤物理环境的变化特征及其生态效应，揭示土壤物理功能演变对土壤质量提升的调控机制。

### 论文核心内容

1. 分析不同恢复类型下土壤物理性质的变化特征，包括土壤容重、穿透阻力、饱和导水率、有效含水量、团聚体稳定性、土壤可蚀性、通气孔隙度和中孔隙度等指标；
2. 研究经济林恢复不同年限（0年、5年、15年、25年、35年）条件下土壤物理性质的动态变化规律；
3. 构建土壤功能评价体系，包括根系支撑功能、水分供给功能、抗侵蚀与抗退化功能以及土壤通气与气体交换功能；
4. 综合评价不同恢复措施和恢复年限下土壤物理质量指数（SPQI）的差异，解释土壤功能之间的协同与权衡关系。

### 本质体现

- 植被恢复方式对土壤物理环境改良效果的差异；
- 经济林恢复过程中土壤物理功能的阶段性变化与功能权衡；
- 土壤物理质量提升机制及其对生态恢复和土地可持续利用的意义。

## 三、复现目标

本实验拟复现研究中的关键图形，包括不同恢复类型和不同恢复年限下的土壤物理指标图、土壤功能得分图、土壤功能雷达图以及土壤物理质量指数图。

### 复现图形清单

1. 土壤容重（BD）与穿透阻力（PR）柱状图；
2. 饱和导水率（Ks）、有效含水量（AWC）及其水分供给功能（SPF2）图；
3. 团聚体平均重量直径（MWD）、土壤可蚀性因子（K）及其抗侵蚀功能（SPF3）图；
4. 土壤通气孔隙度（SAC）、中孔隙度（Mesoporosity）及其通气功能（SPF4）图；
5. 不同恢复类型与恢复年限条件下的土壤功能雷达图；
6. 综合土壤物理质量指数（SPQI）柱状图。

### 图示说明

1. 不同恢复类型下土壤物理性质和土壤功能存在显著差异；
2. 经济林恢复不同年限下土壤物理指标呈现阶段性变化趋势；
3. 不同土壤物理指标共同影响土壤功能表现，且不同功能之间存在一定协同与权衡；
4. 长期自然恢复（林地、草地）有利于显著提升综合土壤物理质量；
5. 经济林恢复虽改善了部分土壤功能，但由于土壤压实等因素，其综合土壤质量提升有限。

### 逻辑关系

> 恢复措施 → 改变土壤物理性质 → 影响根系支撑、水分供给、抗侵蚀和通气等土壤功能 → 决定综合土壤物理质量指数变化 → 影响生态恢复效果和土地利用可持续性
